## 🧩 About

**2XKO ESP Menu** is a curated list of 2XKO open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, frame data display
- **Quality-of-Life Helpers** — combo catalog, input display, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers for Windows.

## ✨ Features

### ESP
- Frame Data Overlay — visualize startup, active, and recovery frames
- Hitbox Viewer — show collision boxes for study
- Combo Recorder — record and replay sequences for practice
- Input Display — on-screen input history

### Wallhack
- Move List Browser — quick reference for all characters
- Color Picker — customize overlay colors and transparency
- UI Scaling — adjust overlay size for different resolutions

### Aimbot
- Training Mode Notes — segment study on any stage
- Dummy Control — set training dummy behavior
- Reset Hotkey — quickly reset positions

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Insert"` | Toggle overlay |
| `process_name` | String | `"2XKO.exe"` | Target process |
| `safe_mode` | Boolean | `true` | Keep conservative defaults |
| `overlay_opacity` | Float | `0.8` | Overlay transparency (0.0-1.0) |
| `show_fps` | Boolean | `true` | Display frame rate |

## 🛠️ Troubleshooting

- **Overlay not showing:** Ensure the game is running in windowed or borderless mode. Try running as administrator.
- **Hotkey not working:** Check if another application is using the same key. Change `menu_hotkey` in config.
- **Game crashes on launch:** Disable any other overlays (e.g., Steam overlay) and verify game files.
- **Performance issues:** Lower overlay opacity or disable FPS counter.
